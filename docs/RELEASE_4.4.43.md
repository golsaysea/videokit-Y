# VideoKit 4.6.0 (正式版)

## 本次正式版核心更新

### 1. 🗂️ 工程管理（前台打开 vs 后台保留）
- 新增 **「🗂️ 工程管理」** 面板（批量表格标签栏 & 主工具栏 & 标签右键菜单均可一键打开）。
- 支持多选勾选要在前台标签栏与任务列表展示的工程标签；暂时不用的工程自动安稳保存在 **后台**（不删除数据，不丢失任务与小分组，重启自动保留），随时一键重新打开或「单独聚焦此工程」。

### 2. ☁️ Cloudflare 远程中控 & Google Drive 防重名智能加载
- 支持 **极简免 KV 版** 与 **高级 KV 网页管理版** Cloudflare Worker 总控模板，一键同步全部 API Key 池（Groq / Gladia / Deepgram / Gemini / ElevenLabs）与每日工程清单。
- 支持直接填写 Google Drive 共享文件夹链接、Google 文档清单或单工程 `.json` 分享链接，自动递归展开与跨机素材重连。
- 新增 **重名 / 同源工程防重复下载机制**：云端列表实时标记 `✅ 本地已加载` / `💤 后台已有同名工程`；重复点击加载或导入同名工程时，自动提示「直接打开本地已有工程（跳过下载）」或「重新下载并原位覆盖更新」，不再每次更新重复堆积标签页。

### 3. ✍️ 署名（AI 水印）随工程打包完整携带与加载继承
- 执行 **「📦 仅打包工程」** / **「导出后复制工程包」** / **「保存项目」** / **「批量表格导出」** 时，自动同步最新文字与图片署名水印（支持 `local-media://` / `file://` 图片路径便携复制与重映射）。
- 他人在任意电脑通过 **「加载项目」**、**「导入工程（覆盖/追加）」** 或 **「☁️ 云端中控加载」** 打开工程时，自动继承并应用包内署名、持久化写入本地配置并立即刷新水印面板与预览，避免遗漏署名。

### 4. 📂 标签小分组与分组打包
- 支持在标签栏创建/折叠/重命名 **小分组**；多选不同分组标签进行 **「📦 仅打包工程」** 时，自动按小分组建立子文件夹并保留完整多分组结构，导入时原样恢复小分组层级。

### 5. 🎨 Studio 主题体验与安全/稳定性加固
- 内置 260+ 预设库与社区预设扩展、100 款 Google 字体管理、Studio 视觉主题与命令面板、右下角非阻塞更新提示气泡 (`_showUpdateCornerToast`)。
- 代码安全加固：强制校验云端远程链接 `http/https` 协议、禁止凭据嵌入与内网 SSRF 地址注入、过滤 `Object` 原型污染键（`__proto__` / `constructor` / `prototype`）并对路径展示进行 HTML 转义。
