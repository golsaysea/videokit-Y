# VideoKit 4.6.1 (正式版)

## 本次 4.6.1 核心更新

### 1. 🎄 圣诞主题与北美风格滚动字幕预设全面升级（`sc-49`～`sc-198`）
- 新增 **50 款圣诞长篇滚动字幕卡片预设**（`sc-149`～`sc-198`），搭配 **12 款圣诞专属材质卡面**（`xmas_*`：勃艮第金箔、苏格兰格纹、伯利恒星夜、教堂彩窗玻璃等）与 **12 款圣诞角标徽章**（`na_xmas_*`），与现有 `sc-49`～`sc-148` 北美祈祷风格形成完整预设库（共 198 款内置滚动卡片样式），并配备大气弹窗式预览工坊与材质/元素筛选。
- 支持圣诞节 **手写笔刷/圣诞挂件饰品与装饰范围选择**（「应用本页」/「应用本标签页」隔离生效，不跨标签泄露）。

### 2. 🖼️ 滚动卡片自动贴合字幕框 + 羽化与渐变完全联动
- 全部 150 款北美/圣诞滚动预设（`sc-49`～`sc-198`）现默认开启 **自动跟随字幕框尺寸**（`bg_width: 0` / `bg_height: 0`、`bg_scroll_follow: true`、`feather_mode: 'clip'`）及安全内边距/角标间距，背景卡片会随字幕框长宽实时伸缩，不再因固定高度造成文字羽化溢出卡外或徽章压字。
- 修复所有主题卡片背景（圣诞/牛皮纸/复古纸/格纹等）与 4 向边缘羽化及正负偏移的联动渲染：调节羽化大小与羽化偏移即可同步控制文字与卡片底板的渐变虚化、内收或外扩。

### 3. ⚡ 操作流畅度与取色器性能优化
- 重构属性面板颜色选择器、十六进制输入、渐变编辑器及数字滑块交互链路：拖拽期间通过 `requestAnimationFrame` 合帧渲染，仅画布与 V2 预览实时刷新；跨任务批量同步、时间线重建、工程自动保存与历史栈改为松手提交或空闲防抖（`220–260ms`），彻底消除选色卡顿与输入丢焦。
- 新增 **滚动卡片离屏位图 LRU 缓存**（8 条），调整正文颜色/高亮/滚动预览时直接复用已渲染卡面位图，交互大幅提速。
- 优化批量表格视图自适应高度计算，确保底部操作按钮始终清晰可见。

### 4. 📦 4.6 系列基础能力继承
- **工程管理与小分组**：支持前台打开/后台保留多工程标签、小分组折叠/分文件夹打包导出。
- **☁️ Cloudflare 远程中控 & Google Drive**：支持免 KV / KV 总控模板与防重名防重复下载覆盖更新。
- **✍️ 署名（AI 水印）全流程便携携带**、100+ 新增谷歌字体与安全/稳定性加固。
