⚠️ 模式选择建议

              

                网页 Token 模式：可使用更多社区音色，但不建议批量大量注册使用，容易触发 IP 异常活动检测，可能导致 IP 被永久封禁而彻底无法访问 ElevenLabs。

                API Key 模式：更稳定安全，建议分散时间注册多个账号获取 Key 做轮询池，但部分社区音色可能无法直接使用。

                💡 请根据自身需求自行衡量选择模式。少量精品用网页模式，批量生产用 API Key 模式。
              

            

            
            

              🔄 Token 失效说明：网页 Token 属于会话凭证，有效期通常为数小时到数天不等。当 Token 失效后，语音生成会报 401 错误，此时需返回语音合成页面重新登录获取新 Token。API Key 则无此限制，长期稳定有效。

📋 粘贴剪辑片段

        
      


      
      

        
        
        
      


      

        
        

          

            
📌 格式说明：每行一个片段，包含「入点」和「出点」
            

            

              支持 Tab 分割（Excel 直接复制）或 空格分割

              时间格式: MM:SS · HH:MM:SS · HH:MM:SS.mmm ·
              HH:MM:SS:FF（帧码）· 纯秒数
            

            

              片段A 00:00:53:19 00:00:57:03
              片段B 00:00:57:03 00:01:02:22
              片段C 00:01:02:22 00:01:04:29

            

              💡 也可以省略名称，只粘贴两列时间；留空出点表示到视频结尾
            

          

        


        
        

          

            
📌 格式说明：直接从 YouTube
              说明栏复制时间戳

            

              每行一个时间戳 + 标题，系统自动将 相邻时间点之间 生成为片段
            

            

              0:00 片头介绍
              2:30 第一章 正文内容
              5:15 第二章 深入讨论
              10:00 总结与结尾

            

              💡 最后一个时间戳到视频结尾为最后一个片段。时间戳和标题的顺序不限。
            

          

        


        
        

          

            
📌 格式说明：直接从 Excel / Google
              Sheets 复制多列数据

            

              系统会自动识别哪一列是名称、哪一列是时间范围、哪些列是字幕

              支持时间范围格式: 14:16—18:43 · 0:30-1:20 · 00:05:00~00:10:00

              第一行如果包含表头关键词，会自动跳过并用作字幕列名称
            

            

              片段名称 剪辑时间段 封面标题 英文-FB 英文-TK
              揭晓第五名 14:16—18:43 (忽略) GOD LET YOU IF YOU'RE
              揭晓第四名 18:44—24:24 (忽略) THE HOLY THIS IS NO

            

              💡 粘贴后系统自动检测列映射。不需要的列（如「封面标题」）会自动归入字幕列，可在导入后手动删除。
